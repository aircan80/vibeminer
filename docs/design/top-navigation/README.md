# Top navigation: Home and Tables

[Open Home](home.html) · [Open Tables](tables.html) · [Home screenshot](home.png) · [Tables screenshot](tables.png)

The selected reference for the horizontal build shell. It came from the Java project ([vibeminer_java #111](https://github.com/aircan80/vibeminer_java/issues/111)).

- Top navigation switches application areas. Each area can have its own internal navigation. There is no global sidebar.
- Tables keeps the Explorer catalogue on the left, a breadcrumb trail above the selected table, and a 340px inspector. Selecting from the catalogue starts a new trail; following a relationship extends it.
- Home uses the selected C overview.
- The mockup's PLANNED/disabled future areas, Preview selector, sidebar alternatives and sample rows are prototype material. Production omits them.
- All quantities and rows are illustrative. Nothing is downloaded or persisted. Schema attribution and limits are in [table research](../tables/RESEARCH.md).
- Descriptive foreign-key labels keep the raw ID next to the label.

Java-era planning for this design: [milestone 5](https://github.com/aircan80/vibeminer_java/milestone/5) (guided discovery and build overview) and [milestone 6](https://github.com/aircan80/vibeminer_java/milestone/6) (area navigation #112, Explorer table browsing #113, descriptive foreign-key labels #109).

Shared UI rules are in [UI guidelines](../../UI-GUIDELINES.md).
