# Build preparation reference

[Open the dedicated preparation view](index.html?option=dedicated&state=indexUnknown). The Java project selected this option for genuine long-running preparation before Home; the port carries it forward as part of the existing workflow.

Back detaches observation, explicit Cancel requests stopping, and completion only navigates an attached matching context. Valid prepared contexts bypass the view after revalidation. Unknown work totals remain indeterminate. See [async work](../../ASYNC-AND-JOBS.md).

Other options, elapsed times, percentages, and fixture controls are comparison/demo material. This HTML performs no real preparation or job persistence.
